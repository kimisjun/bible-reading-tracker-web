# Wave 3B 계획 UI 인수인계

## 설정 탭 구조

### 공통 계획

개인 오프라인판에서 공통 계획은 사용자가 선택하는 기본 전체 성경 계획이다.

- 프리셋: 1년, 6개월, 90일
- 범위: 전체 성경으로 고정
- 입력: 시작일, 읽는 요일, 읽기 순서, 놓친 일정 정책
- 동시에 하나만 활성화
- 변경 시 기존 ReadingEvent는 유지
- 저장 전 첫 7일 미리보기

### 개인 계획

- 이름
- 범위: 전체, 구약, 신약, 특정 책 복수 선택
- 시작일·종료일
- 읽는 요일 복수 선택
- 읽기 순서: 정경, 구약+신약 병행
- 놓친 일정 정책
- 동시에 하나만 활성화

### 미리보기

- 총 장 수
- 읽는 날 수
- 하루 평균 장 수
- 마지막 완료 예정일
- 첫 7일 날짜와 장 범위
- 하루 10장 이상인 날이 있으면 부드러운 경고
- 오류는 필드 근처와 상단 요약에 한국어로 표시

## 오늘 탭 계획 카드

공통 계획과 개인 계획이 모두 있으면 두 카드를 함께 표시한다.

각 카드:

- 계획 이름과 오늘 날짜
- 오늘 장 목록
- 장마다 현재 완료 상태와 `읽었어요`
- `전체 완료`는 미완료 장만 각각 +1 이벤트로 기록
- 전체 완료 이벤트는 하나의 batchId를 공유
- 완료 직후 `오늘도 말씀과 함께 걸으셨습니다` 안내
- 방금 전체 완료한 batch를 한 번에 취소 가능
- 계획이 없는 기존 추천 카드는 계속 유지

## 놓친 일정 UX

- `carry`: `밀린 분량 N장 포함` 표시
- `redistribute`: `남은 기간에 다시 나누었습니다` 표시
- `restart-today`: 변경된 완료 예정일 표시
- 재계산 전에 남은 장 수·변경 종료일·첫 7일을 미리 보여주고 확인
- ReadingEvent 원본은 수정하거나 삭제하지 않는다.

## 접근성·모바일

- 폼 label과 오류 연결
- 요일은 `aria-pressed` 토글 또는 checkbox
- 44px 이상 터치 영역
- 미리보기 변경은 `aria-live=polite`
- 320px에서 가로 스크롤 없음
- 완료 상태는 색상뿐 아니라 체크와 텍스트로 표시
- 다크 토큰과 reduced motion 유지
