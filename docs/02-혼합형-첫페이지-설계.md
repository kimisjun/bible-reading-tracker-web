# 혼합형 성경통독 웹앱 첫 페이지 설계

- 확정일: 2026-07-30
- 상태: 설계안, 개발 전
- 중심 방식: 오늘 계획 + 자유 통독표 혼합형
- 주간 기준: 월요일 00:00부터 일요일 23:59까지, 한국 시간

## 1. 첫 페이지의 목적

사용자가 로그인한 뒤 다른 메뉴를 찾지 않아도 아래 네 가지를 바로 알 수 있어야 한다.

1. 오늘 읽을 말씀
2. 오늘 실제로 읽은 장 수
3. 월요일부터 일요일까지 이번 주에 읽은 장 수와 요일별 내역
4. 성경 전체 1,189장 중 현재까지의 고유 통독 진도

첫 화면은 통계 대시보드가 아니라 **오늘 말씀을 읽고 기록하는 실행 화면**으로 유지한다.

## 3. PC·태블릿 구성

- 왼쪽 넓은 영역: 오늘 읽기와 완료 버튼
- 오른쪽 상단: 오늘 읽은 분량
- 오른쪽 하단: 이번 주 월–일 막대그래프
- 아래 전체 폭: 전체 통독 진도와 성경 66권으로 이동
- 관리자 기능은 첫 페이지에 섞지 않고 별도 관리자 메뉴로 분리

## 4. 오늘 읽은 분량 계산

### 표시 값

```text
오늘 읽은 분량 = 오늘 생성된 유효한 ReadingEvent의 장 수 합계
```

예시:

- 오늘 계획으로 누가복음 5–6장 읽음: 2장
- 자유 통독으로 시편 1–2장 읽음: 2장
- 오늘 합계: 4장

### 중복 방지

- 같은 계획의 동일한 장을 실수로 두 번 누른 경우 한 번만 계산한다.
- 이미 읽은 장을 실제로 다시 읽은 경우 `다시 읽음`을 선택해야 통독량에 추가한다.
- 기록을 취소하거나 수정하면 오늘·주간 합계도 즉시 다시 계산한다.

## 5. 이번 주 통독량 계산

- 한 주는 **월요일 00:00부터 일요일 23:59까지**로 정한다.
- 한국 시간 `Asia/Seoul`을 기준으로 한다.
- 월·화·수·목·금·토·일의 장 수를 각각 보여 준다.
- 미래 요일은 `-`, 읽지 않은 지난 요일은 `0`으로 구분한다.
- 이번 주 총합과 사용자가 정한 주간 목표를 함께 보여 준다.
- 주간 목표는 비교·순위가 아니라 개인의 생활 리듬을 돕는 참고값이다.

예시:

```text
월 3장 + 화 5장 + 수 6장 + 목 4장 = 이번 주 18장
```

## 6. 전체 통독 진도와 통독량의 차이

| 항목 | 계산 방식 | 목적 |
|---|---|---|
| 전체 통독 진도 | 한 번 이상 읽은 서로 다른 장의 수 | 성경 전체를 얼마나 통독했는지 확인 |
| 오늘 통독량 | 오늘 실제 읽은 장 수의 합 | 오늘 읽은 분량 확인 |
| 주간 통독량 | 월–일 실제 읽은 장 수의 합 | 이번 주 읽기 습관 확인 |
| 장별 읽은 횟수 | 해당 장을 명시적으로 읽은 횟수 | 반복 통독 이력 확인 |
| 권별 완독 열매 | 한 권 전체를 완독한 횟수, 최대 10회 | 반복 완독 성취 확인 |

예를 들어 누가복음 5장을 이전에 읽었더라도 오늘 `다시 읽음`으로 기록하면:

- 전체 1,189장 진도에는 새 장으로 추가되지 않는다.
- 오늘 통독량에는 1장이 추가된다.
- 누가복음 5장의 읽은 횟수는 1회 증가한다.

## 7. 필요한 핵심 데이터

```text
ReadingEvent
- id
- userId
- readDate
- timezone
- bookId
- chapterNumber
- source: DAILY_PLAN | FREE_READING | REREAD
- planAssignmentId: 선택
- recordedAt
- cancelledAt: 선택

ChapterProgress
- userId
- bookId
- chapterNumber
- firstReadAt
- lastReadAt
- readCount

DailyReadingSummary
- userId
- date
- plannedChapterCount
- freeReadingChapterCount
- rereadChapterCount
- totalChapterCount

WeeklyGoal
- userId
- weekStartDate
- targetChapterCount
```

일일·주간 합계는 ReadingEvent에서 다시 계산할 수 있게 하며, 화면 속도를 위해 요약값을 보조로 저장할 수 있다.

## 8. 접근성 기준

- `오늘 읽기`와 `읽었어요`를 첫 화면에서 가장 크고 선명하게 표시
- 통계 숫자는 설명 문구보다 크게 표시
- 막대그래프에 숫자도 함께 표시하여 색만으로 구분하지 않음
- 버튼 최소 48×48px
- 큰 글자 모드에서 레이아웃이 세로로 자연스럽게 재배치
- ‘0장’을 실패처럼 빨간색으로 표시하지 않음
- “읽지 못했어요” 대신 “오늘부터 이어서 읽기” 사용
- 주간 목표를 달성하지 못해도 벌점·연속 기록 초기화 없음

## 9. 첫 페이지에서 제외할 요소

- 개인 순위와 소그룹 순위
- 관리자 통계
- 복잡한 연간 차트
- 교인 소셜 피드
- 광고와 유료 기능 안내
- AI 성경 해석
- 많은 설정 버튼

## 10. 현재 확정 사항

- 교인 계정형
- 로그인 후보: 휴대전화 번호 + 비밀번호
- 오늘 계획과 자유 통독표를 함께 제공하는 혼합형
- 오늘 읽은 장 수를 첫 페이지에 표시
- 월요일부터 일요일까지 요일별 통독량과 주간 총합을 첫 페이지에 표시
- 전체 통독 진도와 반복 읽기 통독량을 분리 계산
