# 계정형 서버판 역할·권한 및 개인정보 설계

- 상태: 설계 확정안
- 역할: 성도, 관리자 2단계
- 기본 원칙: 개인 통독 기록은 비공개, 관리자에게는 전체 집계만 제공

## 1. 성도 권한

성도는 본인의 데이터만 관리한다.

- 휴대전화 번호와 비밀번호로 로그인
- 본인 통독 계획 생성·변경·중단
- 오늘 읽기, 자유 통독, 다시 읽기 기록
- 오늘·주간·월간·전체 통독 현황 확인
- 66권·1,189장 장별 기록과 권별 10회 완독 열매 확인
- 기록 수정·취소
- 알림, 큰 글자, 고대비 등 개인 설정
- 본인 데이터 다운로드
- 계정 탈퇴와 개인정보 삭제 요청
- 관리자에게 개인 기록 열람을 일정 기간 허용하거나 즉시 철회

## 2. 관리자 권한

관리자는 계정과 교회 공동 계획을 운영하지만 성도의 신앙생활을 평가하지 않는다.

### 계정 지원

- 성도 계정 생성·활성화·비활성화
- 임시 비밀번호 발급과 비밀번호 초기화
- 본인 확인 후 휴대전화 번호 변경
- 중복 계정 확인과 병합 지원
- 탈퇴·삭제 요청 처리

### 교회 운영

- 교회 공통 통독 계획 생성·게시·종료
- 공지와 정형화된 격려 메시지 게시
- 전체 가입자·활성 사용자·주간 참여자 수 확인
- 교회 전체 일일·주간 통독 장 수 확인
- 공동 계획의 전체 참여율 확인

### 기본적으로 볼 수 없는 정보

- 특정 성도가 읽은 성경과 장
- 특정 성도의 하루·주간 통독량
- 개인 통독 시간
- 개인 묵상·기도·메모
- 개인의 실패·누락 목록
- 개인별 순위나 신앙 점수

## 3. 개인 기록 열람 동의

성도가 계정 지원이나 기록 복구 도움을 요청한 경우에만 제한적으로 허용한다.

### 동의 절차

1. 성도가 앱에서 `관리자에게 도움 요청`을 누른다.
2. 열람 범위와 기간을 보여 준다.
3. 성도가 명시적으로 동의한다.
4. 관리자는 필요한 기록만 확인한다.
5. 기간이 끝나면 권한이 자동 종료된다.
6. 성도는 언제든 즉시 철회할 수 있다.

### 권장 열람 범위

- 기본 기간: 24시간
- 최대 기간: 7일
- 기본 범위: 기록 오류 확인에 필요한 읽기 이벤트와 동기화 상태
- 묵상·기도·메모는 별도의 추가 동의 없이는 제외

### 감사 기록

다음을 삭제 불가능한 감사 로그에 남긴다.

- 어떤 관리자가
- 어느 성도의
- 어떤 범위를
- 언제 열람했는지
- 어떤 이유였는지

성도는 본인 계정에서 최근 관리자 열람 내역을 확인할 수 있다.

## 4. 관리자 집계 화면

개인을 식별하지 않는 집계를 기본으로 한다.

```text
이번 주 교회 통독 현황
- 참여 성도: 128명
- 읽은 장 수: 2,318장
- 오늘 참여: 74명
- 공통 계획 진행: 41%
```

다음 기능은 제공하지 않는다.

- 통독량 상위 성도
- 통독량 하위 성도
- 미참여자 공개 명단
- 신앙 점수
- 소그룹 또는 성도 간 경쟁 순위

## 5. 최소 개인정보

필수 수집 후보:

- 휴대전화 번호
- 암호화된 비밀번호 정보
- 표시 이름
- 계정 상태
- 통독 이벤트
- 서비스 운영에 필요한 접속·감사 기록

선택 수집 후보:

- 소그룹
- 알림 시간
- 큰 글자·화면 설정

초기 버전에서 수집하지 않을 정보:

- 주민등록번호
- 생년월일 전체
- 주소
- 직분·가족관계
- 위치 정보
- 연락처 목록

## 6. 보안 원칙

- 비밀번호 원문 저장 금지
- Argon2id 또는 검증된 강한 해시 사용
- 관리자 다중 인증 적용
- 역할 기반 권한 검사를 서버에서 수행
- 관리자 화면의 모든 개인정보 작업을 감사 로그에 기록
- 로그인 시도 횟수 제한과 계정 잠금
- 전 구간 HTTPS
- 민감 데이터의 백업·복구 절차 마련
- 실제 휴대전화 번호와 통독 데이터는 공개 GitHub 저장소에 저장하지 않음

## 7. 확정 사항

- 역할은 성도와 관리자 2단계
- 관리자는 전체 집계만 기본 열람
- 개인 통독 기록은 성도 동의가 있을 때만 기간 제한 열람
- 개인 순위와 신앙 점수는 제공하지 않음
- 관리자 열람 이력을 성도에게 공개
