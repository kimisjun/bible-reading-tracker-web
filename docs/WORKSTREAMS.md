## Wave 3 권장 병렬 분할

| 작업 | 소유 범위 | 선행 조건 |
|---|---|---|
| 계획 도메인 | `src/domain/plan*` | 없음 |
| 계획 설정 UI | `src/features/settings/**` | 계획 계약 확정 |
| 오늘 계획 UI | `src/features/today-plan/**` | 계획 계약 확정 |

계획 계약을 먼저 짧은 순차 작업으로 확정한 뒤 UI 두 작업을 병렬화한다.

## 통합 규칙

각 작업은 다음 조건을 모두 충족해야 통합한다.

- 지정 브랜치·worktree·파일 범위 준수
- RED → GREEN 증거
- 집중 테스트와 전체 테스트 통과
- ESLint·build·audit 통과
- 독립 리뷰 차단사항 0
- 통합 후 실제 브라우저 스모크 테스트
