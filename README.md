# 말씀과 함께 걷는 성경통독표 웹앱

성경 66권 1,189장을 장별로 체크하고, 각 권을 10회까지 반복 완독 기록하는 오프라인 우선 웹앱입니다.

## 바로 실행

`index.html`을 Chrome 또는 Edge로 열면 됩니다. 기록은 현재 브라우저의 localStorage에 자동 저장됩니다.

## 주요 기능

- 구약 39권·신약 27권, 총 1,189장 장별 체크
- 각 권별 10회 완독 열매
- 전체·구약·신약 진행률 자동 계산
- 성경 검색과 읽는 중 필터
- 일반 글자/큰 글자 전환
- JSON 백업 저장 및 복원
- 인쇄
- 웹 서버에 배포하면 서비스 워커를 통한 오프라인 사용 지원

## 로컬 웹 서버 실행

```bash
python -m http.server 8080
```

브라우저에서 `http://localhost:8080`으로 접속합니다.

## 데이터 주의

기록은 서버 계정이 아니라 사용 중인 기기의 브라우저에 저장됩니다. 브라우저 데이터를 삭제하거나 기기를 바꾸기 전에는 반드시 **백업 저장**을 눌러 JSON 파일을 보관하세요.
